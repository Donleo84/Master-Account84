# Retro Gaffer

Retro-styled football management game inspired by Premier Manager / LMA / early Championship Manager eras, with modern teams from Europe's major leagues.

## Features

- Pick a club from: Premier League, La Liga, Serie A, Bundesliga, Ligue 1.
- Full double round-robin seasons with league tables and season rollover.
- Play your matches with live pixel pitch, commentary, mentality toggles, and speed controls (1x/2x/4x/8x).
- Full management loop:
  - tactics and formation controls
  - transfers (buy/sell)
  - wage and budget management
  - sponsorship and matchday income
  - stadium expansion and facilities upkeep

## Run

Open `index.html` in a modern browser.

For local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
